# CbS11 — Enterprise IT Landscape (School 21)

**Status:** completed and accepted by School 21 (confirmed by the project author). The assessed deliverables remain in the private School 21 GitLab; this public file is an independent portfolio summary, not the original assignment or an export of internal materials.

## Project focus

Design and secure the IT infrastructure of a model software company (about 10–15 employees). Apply the confidentiality, integrity and availability (CIA) principles and defense in depth.

## Completed educational project: scope and deliverables

| Area | Skills demonstrated in the assignment | Deliverables |
| --- | --- | --- |
| Network architecture | LAN design, diagrams.net (draw.io), device links, internal/employee/server segments and DMZ | Topology diagram |
| Asset inventory | IPv4 addressing and subnets, OS/software versions, local/domain accounts, Active Directory context | Spreadsheet of IT assets |
| Infrastructure protection | Endpoint protection, firewalls, VPN, security zoning, defense in depth, risk-informed controls | Protected infrastructure topology and security controls inventory |
| Remote access (additional task) | Segmented access for remote workers, isolated server zone, terminal server | Optional expanded topology |

The assignment also addresses reviewing AI-generated proposals, identifying missing inventory assets, checking spreadsheet completeness, explaining VPN selection and validating network security measures. This public summary describes the **covered project scope** without claiming that every optional exercise was independently verified from the private repository.

## Takeaways

- Explain the CIA triad and its importance in enterprise architecture
- Segment a network to separate user systems, internal servers and internet-exposed services
- Inventory assets and map security controls to endpoints, networks and applications
- Understand practical trade-offs among VPN technologies and access restrictions
- Document infrastructure and security decisions using diagrams and structured tables

## Publication boundaries

The private submission, original task text, company inventories, internal network schemes, addresses, credentials and files are intentionally excluded. This is a learning project, not a real corporate production deployment.
